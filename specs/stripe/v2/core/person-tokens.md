# Person Tokens

Person Tokens are single-use tokens which tokenize person information, and are used for creating or updating a Person.

## Endpoints

### Create a Person Token

- [POST /v2/core/accounts/:account_id/person_tokens](person-tokens/create.md)

### Retrieve a Person Token

- [GET /v2/core/accounts/:account_id/person_tokens/:id](person-tokens/retrieve.md)
