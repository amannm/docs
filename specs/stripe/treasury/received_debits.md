# Received Debits

ReceivedDebits represent funds pulled from a [FinancialAccount](received_debits.md#financial_accounts). These are not initiated from the FinancialAccount.

## Endpoints

### Retrieve a ReceivedDebit

- [GET /v1/treasury/received_debits/:id](received_debits/retrieve.md)

### List all ReceivedDebits

- [GET /v1/treasury/received_debits](received_debits/list.md)

### Test mode: Create a ReceivedDebit

- [POST /v1/test_helpers/treasury/received_debits](received_debits/test_mode_create.md)
