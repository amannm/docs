# Accounts Receivable

API for creating and managing invoices

<Callout icon="📘" theme="info">
  Access to this API requires your organization to have a Mercury subscription. See information, benefits,  and sign up for a subscription <Anchor label="here" target="_blank" href="https://mercury.com/pricing">here</Anchor>. After you subscribe, you should get access to this endpoint immediately. If you are still getting a 403 after upgrading please contact [api@mercury.com](mailto:api@mercury.com).
</Callout>

<Callout icon="🚧" theme="warning">
  The Accounts Receivable API is currently not available in the sandbox environment.
</Callout>

<br />

### Authorization

This API uses standard API tokens, which can be managed in the UI at [https://app.mercury.com/settings/tokens](https://app.mercury.com/settings/tokens)
